# 制造试点质量证据与产线启用边界

包装件试用、原料谱系、盲复测与客户批约定。资料中的企业、机构、事件和观测全部为合成资料。

## 交换格式

`input/` 是同一经营流程各来源的资料包。每个 JSONL 文件一行一个对象，编码为 UTF-8。日期为当地自然日，带时区的时间戳使用 UTC+08:00。没有值的字段用 `null`，对象身份以各表说明的主键为准。输入文件的排列顺序不代表业务发生顺序。

- `batches.jsonl` 记录入料和各工厂的生成批，含盲复测目标时段。
- `lineage.jsonl` 记录原料批向多个产线批投料的凭证与后续更正。
- `tests.jsonl` 记录实际判定、盲复测和疑件复检记录。
- `meters.jsonl` 记录设备维护和两套口径之间的原始复测桥接证据。
- `release.jsonl` 记录客户约定和批次物流状态。
- `policy.jsonl` 记录启用范围、目标和复测资源。

字段、单位和来源约定见 [资料字典](资料字典.md)。

## 本地读取与核对

使用 Python 3.11.2，无需安装第三方包。以下命令从项目根目录运行。

```sh
python3 -m source_bundle input
python3 -m unittest discover -s tests
```

第一条命令检查交付格式并输出来源表行数，第二条命令核对样本和格式异常。其他资料包可替换为同格式的目录。
